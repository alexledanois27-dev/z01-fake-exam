# Tableaux, chaînes et indices

## Objectif

Manipuler une séquence en décidant ce qui est copié, muté ou conservé.

## À savoir

- `slice(a,b)` exclut la borne b et ne modifie pas le tableau ; `splice` modifie le tableau.
- `reverse()` et `sort()` modifient le tableau concerné. `[...values]` ne copie que le premier niveau.
- `for...of` parcourt des valeurs ; `for...in` parcourt des clés.
- Les indices de chaînes sont des unités UTF-16 ; `[...text]` parcourt les points de code, pas forcément les graphèmes visuels complets.

## Exemple isolé de syntaxe

```javascript
const source = [8, 3, 6, 1];
const fragment = source.slice(1, 3);
const reversed = [...fragment].reverse();
console.assert(source[1] === 3);
console.assert(reversed.join(",") === "6,3");
const letters = [..."a🙂b"];
console.assert(letters.length === 3);
```

Cet exemple illustre une notion ; il ne constitue pas la solution complète d’un
exercice. Conserver la signature et les restrictions annoncées dans la consigne.

## Pièges fréquents

- Croire qu’une copie superficielle duplique aussi les sous-tableaux.
- Modifier l’entrée alors que le correcteur attend qu’elle reste intacte.
- Oublier le dernier bloc incomplet ou les espaces d’un texte.

## Vérification rapide

- Je précise l’unité des indices.
- Je teste tableau vide, singleton et doublons.
- Je sais quelles méthodes mutent.

## À essayer seul

Découper une liste en deux vues copiées, puis modifier un sous-objet pour observer les limites de la copie superficielle.
