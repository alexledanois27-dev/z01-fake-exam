# Closures, curryfication et composition

## Objectif

Conserver un contexte entre appels et assembler des transformations.

## À savoir

- Une closure accède aux variables de sa portée extérieure.
- La curryfication reçoit des arguments en plusieurs appels : `f(a)(b)`.
- Une fonction renvoyée peut conserver un état ; distinguer l’état partagé entre appels de l’état propre à une nouvelle instance.
- Une composition doit préciser dans quel ordre les transformations s’appliquent et ce qui est conservé dans l’historique.

## Exemple isolé de syntaxe

```javascript
function makeOffset(offset) {
  return function apply(value) { return value + offset; };
}
const plusTwo = makeOffset(2);
const plusTen = makeOffset(10);
console.assert(plusTwo(4) === 6);
console.assert(plusTen(4) === 14);
const times = (factor) => (value) => factor * value;
console.assert(times(3)(5) === 15);
```

Cet exemple illustre une notion ; il ne constitue pas la solution complète d’un
exercice. Conserver la signature et les restrictions annoncées dans la consigne.

## Pièges fréquents

- Exécuter un callback pendant la construction au lieu de le conserver.
- Partager un objet mutable entre des instances supposées indépendantes.
- Inverser les paramètres ou l’ordre des étapes.

## Vérification rapide

- Je connais le nombre d’appels attendu.
- Deux fabriques distinctes gardent des contextes indépendants.
- Je distingue une fonction et le résultat de son appel.

## À essayer seul

Créer une fabrique de fonctions puis composer deux transformations, en observant que leur ordre peut changer le résultat.
