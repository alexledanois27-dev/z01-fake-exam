# Promesses et async/await

## Objectif

Distinguer la création d’une promesse, son attente et le traitement de son échec.

## À savoir

- Une fonction async retourne une promesse ; `await` suspend cette fonction, pas tout le programme.
- Une exception dans une fonction async devient un rejet. Traiter les rejets avec try/catch ou catch.
- `Promise.all` conserve l’ordre des entrées et échoue si une promesse rejette ; `race` suit le premier règlement, réussite ou échec.
- Créer toutes les promesses avant de les attendre peut lancer des tâches en parallèle. Attendre dans une boucle impose souvent une séquence.

## Exemple isolé de syntaxe

```javascript
async function describe(value) {
  return `item:${value}`;
}
async function demo() {
  const values = await Promise.all([describe(2), describe(1)]);
  console.assert(values.join(",") === "item:2,item:1");
}
demo().catch(console.error);
```

Cet exemple illustre une notion ; il ne constitue pas la solution complète d’un
exercice. Conserver la signature et les restrictions annoncées dans la consigne.

## Pièges fréquents

- Oublier return dans un then ou oublier await.
- Attendre que race annule les autres tâches : il ne le fait pas.
- Confondre ordre d’achèvement et ordre des résultats de all.

## Vérification rapide

- Je sais à quel moment la tâche démarre.
- Les rejets ont un traitement.
- Je teste une réussite immédiate et un échec.

## À essayer seul

Lancer deux tâches de durées différentes et comparer l’ordre d’affichage à l’ordre retourné par Promise.all.
