# Comparateurs et étapes de tri

## Objectif

Comparer deux valeurs et respecter les mesures exactes d’un algorithme de tri.

## À savoir

- Un comparateur retourne un nombre négatif, nul ou positif ; pas simplement un booléen.
- Le tri natif sans comparateur trie des représentations de chaînes.
- Tri à bulles : comparer des voisins. Tri par insertion : insérer une valeur dans un préfixe déjà trié.
- Si l’exercice compte comparaisons, échanges ou passages, écrire précisément quand chaque compteur augmente.

## Exemple isolé de syntaxe

```javascript
const source = [12, 3, 7];
const ordered = [...source].sort((a, b) => a - b);
console.assert(ordered.join(",") === "3,7,12");
const byLength = (a, b) => a.length - b.length;
console.assert(byLength("un", "trois") < 0);
```

Cet exemple illustre une notion ; il ne constitue pas la solution complète d’un
exercice. Conserver la signature et les restrictions annoncées dans la consigne.

## Pièges fréquents

- Utiliser le tri natif quand le sujet exige un algorithme précis.
- Compter un décalage comme un échange sans vérifier la définition.
- Modifier l’entrée si la fonction doit renvoyer une copie.

## Vérification rapide

- Je teste des valeurs égales.
- Je trace chaque étape sur trois éléments.
- Les compteurs correspondent aux opérations demandées.
