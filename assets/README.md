# Assets de l’interface

- `z01-logo.png` : logo fourni par l’utilisateur ; rendu noir par CSS.
- `wrong-answer.gif` : réaction Picard / facepalm, fournie via Tenor.
  Source : https://tenor.com/view/star-trek-picard-facepalm-i-cant-even-omg-really-gif-23538368
  Fichier : https://media1.tenor.com/m/LRtRSo1uhQsAAAAC/star-trek-picard.gif
  Les droits du contenu d’origine restent à leurs titulaires ; ce fichier n’est
  pas placé sous la licence du code de l’application.

Les médias sont servis localement, sans appel à Tenor depuis le navigateur.
Une nouvelle ressource publique doit être ajoutée explicitement dans
`backend/http_static.go`.
