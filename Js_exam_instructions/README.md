# Copie de secours des énoncés JavaScript

Le serveur charge en priorité le checkpoint `/rouen/cursus-cda/checkpoint-js`
depuis l’API publique Zone01 Normandie. Les fichiers de ce dossier constituent
un snapshot local de secours, synchronisé le 28 octobre 2026.

Les identifiants historiques des fichiers sont conservés pour la progression et
les aides. Les alias vers les noms officiels sont dans `backend/js_catalog.go`
et `backend/exercises.go`. En fonctionnement connecté, les noms de fichiers
attendus sont ceux du catalogue officiel, pas ceux de ce dossier.
